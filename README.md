# Super Mario+

A small platformer game made in JavaScript.

Play it in your browser on [https://matthewtannous.github.io/web-game](https://matthewtannous.github.io/web-game)

[Source code](https://github.com/matthewtannous/web-game)

## Notes
- A camera to follow the player is not needed. Each level is only one "screen".
- For now, some objects do not have a sprite and so are drawn as a rect.
- Level 5 is still missing. It will be added soon.
