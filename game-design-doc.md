## Introduction
Color coded is a 2D platforming game in which players control a character capable of changing between three different colors. Players must use color-matching mechanics, jumping, and environmental awareness to navigate challenging levels, avoid deadly obstacles, and collect gifts to progress.

The game is intended for casual gamers and those who enjoy platforming challenges.

## Game Overview
Chromatic Escape is a side-scrolling 2D platformer where the player navigates through different environments by jumping between colored platforms.

The character can switch between three colors: red, blue, and green.

Each platform is assigned one of these colors. The player can land on a colored platform only when their character has the matching color.

Black platforms are exceptions because they are always solid and can be used regardless of the player's current color.

The game begins with a menu that allows players to start the game or access a tutorial.
